pacmanGPS

Juego clásico de Pac-Man desarrollado en Java

Disfruta del clásico juego de Pac-Man con una interfaz gráfica moderna desarrollada en Java utilizando Swing. Controla a Pac-Man, evita a los fantasmas y recolecta todos los puntos para ganar.

📋 Instrucciones de Instalación

  1. Asegúrate de tener Java 17 o superior instalado en tu sistema
  2. Descarga el archivo pacmanGPS.jar
  3. Abre una terminal en la carpeta donde descargaste el archivo
  4. Ejecuta el siguiente comando:
java -jar pacmanGPS.jar
